## STEP 1: Open in VS Code

1. Extract the ZIP file
2. Right-click the `portfolio` folder → **Open with VS Code**
3. You should see the 3 files in the Explorer panel (left sidebar)

---

## OPTION A: Deploy to Netlify (Easiest — RECOMMENDED ✅)

### Method: Drag & Drop (No account setup needed!)

1. Go to **https://netlify.com**
2. Click **Sign up** → use your GitHub or Google account
3. After logging in, scroll down to the bottom of the dashboard
4. You'll see a box that says **"Want to deploy a new site without connecting to Git?"**
5. **Drag and drop your entire `portfolio` folder** into that box
6. Wait ~10 seconds... 🎉 Your site is LIVE!
7. Netlify gives you a free URL like: `https://random-name-123.netlify.app`
8. To rename it: **Site settings → Change site name** → type something like `harlson-gardose`
   - Your URL becomes: `https://harlson-gardose.netlify.app`

---

## OPTION B: Deploy to Vercel

1. Go to **https://vercel.com**
2. Sign up with GitHub (you'll need a GitHub account)
3. Click **"Add New Project"**
4. Choose **"Import from local"** or drag your folder
5. Click **Deploy**
6. Free URL: `https://your-project.vercel.app`

---

## OPTION C: GitHub Pages (Also Free)

1. Create a **GitHub account** at https://github.com
2. Click **"New Repository"** → name it `portfolio`
3. Upload all your files (drag & drop in the browser)
4. Go to **Settings → Pages → Source → main branch**
5. URL: `https://yourusername.github.io/portfolio`

---

## ✅ QUICK CHECKLIST BEFORE DEPLOYING:
- [ ] All 3 files are in the right folders
- [ ] `index.html` is in the ROOT of the folder (not inside a subfolder)
- [ ] Test locally first: open `index.html` in your browser

---

## 💡 TIP: Test Locally First

Before deploying, just double-click `index.html` to open it in your browser.
Everything should look great without needing a server!
